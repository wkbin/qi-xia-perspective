# 齐夏战术工具库：快速决策工具与参考卡

## 一、快速决策流程

### 流程1：是否参加一个游戏/事件？

```
遇到新游戏/事件
        ↓
【第1步】收集基本信息（规则、参与者、奖励、罚则）
        ↓
        信息充分? 
        ├─ 否 → 推延决定，继续收集
        └─ 是 ↓
【第2步】评估参与者构成
        ├─ 我方有优势? 是 → 参加
        ├─ 势均力敌? → 评估学习价值
        └─ 我方劣势? → 第3步
【第3步】计算不参加的代价
        ├─ 敌手会因此变强? 是 → 参加（防守性）
        ├─ 没人强制参加? → 不参加（保存资源）
        └─ 被强制参加? → 参加（最优策略）
【第4步】设计备选方案
        ├─ 设定失败退出条件
        ├─ 准备应急资源
        └─ 预先分配任务
        ↓
        执行
```

**应用示例**：《说谎者》游戏
- 第1步：9人、1说谎者、投票制、9人活或全死
- 第2步：我方无特殊优势，但逻辑推理能力强
- 第3步：不参加 = 他人获得"回响"、与规则系统失联
- 第4步：设计"反向说谎"策略，预案是"全力说真话获得信任"
- 结果：参加并赢

### 流程2：是否信任这个人？

```
遇到新人物
        ↓
【筛选层】
├─ 他掌握关键信息/能力吗?
│  ├─ 否 → "不需要信任，隔离使用"
│  └─ 是 ↓
├─ 他的行为与声称是否一致?
│  ├─ 否 ↔ 高风险（可能被操纵）
│  └─ 是 ↓
├─ 他的利益与我方是否一致?
│  ├─ 否 → "有条件合作，不信任"
│  └─ 是 ↓
【信任度量】
├─ 信任度 = (能力等级) × (一致性评分) × (共同利益权重)
├─ 高信任 (>0.8) → 共享关键信息
├─ 中信任 (0.3-0.8) → 有条件合作
└─ 低信任 (<0.3) → 最小化暴露
```

**应用示例**
- 乔家劲：能力强 + 行为一致 + 共同主人翁意识 → 高信任
- 秦丁冬：能力中等 + 行为不一致 + 利益不明 → 低信任
- 陈俊南：能力强 + 行为有原则 + 共同生存利益 → 中高信任

### 流程3：如何回应团队成员的背叛/问题？

```
成员提出质疑或表现出背离迹象
        ↓
【第1步】评估威胁等级
├─ 能立即伤害团队? 
│  ├─ 是 → 立即隔离/出卖（防守性）
│  └─ 否 ↓
├─ 他掌握机密信息?
│  ├─ 是 → 快速处理（信息泄露风险）
│  └─ 否 ↓
└─ 他还有剩余价值?
   ├─ 是 → 重新评估（可能翻转）
   └─ 否 → 放弃（资源解脱）
【第2步】选择回应方式
├─ 威胁高+价值低 → 出卖给敌手
├─ 威胁中+价值中 → 冷流放（自然离开）
├─ 威胁低+价值高 → 心理谈判（翻转）
└─ 威胁低+价值低 → 忽视（自动瓦解）
【第3步】防守和清理
├─ 防止信息泄露
├─ 填补他留下的空缺
└─ 向团队宣示"后果"（维持威慑）
```

**应用示例**
- 赵医生：威胁中（掌握团队战力）+ 价值低（能力可替代）→ 冷漠放弃
- 韩一墨：威胁低（已心理崩溃）+ 价值低（自动形同虚设）→ 忽视
- 秦丁冬：威胁中（可能泄露计划）+ 价值低（可被替代）→ 隔离使用

### 矩阵2：决策可靠性评估矩阵

```
                    信息完整度（0-100）
                    ↑
           100   [ 最优决策区 ]
            |    /              \
            |   / 中等信心      \
            |  /   决策区      \
            | /                  \
            |/________★_________\
         50 |   低信心决策区     
            |\                  /
            | \     高风险    /
            |  \    决策    /
            |   \          /
            0   [_________]
                0    50    100
                决策时间压力
```

**位置解释**：
- ★ 当前位置：信息70% + 时间压力60% = 中等信心决策
- 左上：最优决策（充分信息+充足时间）
- 右上：有风险但必要（充分信息+时间紧张）
- 左下：高风险（信息不足+时间充足） → 应该继续收集
- 右下：极限决策（信息严重不足+时间紧张） → 基于直觉

### 指南2：根据敌手分析优化配置

```
敌手类型 → 对应克制策略 → 团队配置调整

├─ 克制策略：分散目标，破坏组织结构
├─ 需要的能力：信息优势 + 中层分化

├─ 克制策略：最小化关键人物暴露，建立验证机制
├─ 需要的能力：多维度验证 + 心理韧性
└─ 配置：陈俊南（记忆锚定）+ 乔家劲（心理支撑）+ 齐夏（决策稳定性）

能力系敌手（高级生肖）
├─ 克制策略：对位击杀 + 能力克制

└─ 配置：地虎（战斗）+ 社畜鼠（分析）+ 齐夏（协调）

系统型敌手（终焉之地本身）
├─ 克制策略：理解规则 > 破坏规则
├─ 需要的能力：规则分析 + 多维度突破
└─ 配置：陈俊南（历史分析）+ 开放性团队 + 齐夏（理论构建）
```

### 示例档案：楚天秋

```
敌手名称: 楚天秋

【基本信息】
- 代号/身份: 天堂口领导
- 掌握的权力: 组织资源 + 人脉网络 + 心理操纵
- 已知目标: 扩大天堂口影响力，吸纳能力者
- 威胁等级（1-10）: 8（组织威胁度）

【能力评估】
- 已确认能力: 心理诱导、资源配置、组织管理
- 推测能力: 可能掌握某些政治或商业势力
- 克制我方的点: 用承诺和身份认同瓦解团队凝聚力
- 我方克制的点: 易被理性分析识破、承诺容易失效
- 能力上限评估: 中等（依赖他人执行，自身战力不明）

【心理档案】
- 核心动机: 权力扩张和组织成就感
- 隐藏焦虑: 被发现为"虚伪"，组织失控
- 对我方的评估（推测）: "有才华但过于理性，容易被孤立"
- 可能的诱饵: 提升我的权力地位，给团队更好的资源
- 可能的陷阱: 用"副首领承诺"逐个瓦解团队成员

【对位策略】
- 直接对抗: 不可行（他掌握资源优势）
- 迂回绕过: 可行（通过渗透分化他的组织）
- 同舟共济: 有限可行（短期合作可能，长期冲突必然）
- 绝对隔离: 可行但成本高（需要完全脱离组织系统）

【决策】
推荐策略: 迂回绕过 + 有限合作
理由: 直接对抗损失太大，完全隔离也不现实。最优是利用与他的共同利益（对生肖系统的理解）进行战术合作，同时暗中分化其组织。
备选方案: 如果他威胁到生存，则转向绝对隔离（如有必要可以将其交给生肖系统处理）
失败退出条件: 一旦发现他掌握了对我致命的信息，立即执行应急计划B（离开组织范围）
```

## 六、应急决策卡

### 突发状况1：核心人物突然失踪/背叛

```
第0秒: 确认是否失踪/背叛
  ↓
第5秒: 评估他掌握的关键信息
  ↓
第10秒: 启动信息损控（通知其他成员改变计划）
  ↓
第30秒: 评估他对敌方的价值
  ├─ 高 → 立即找到/中立他
  ├─ 中 → 加强防守，被动等待
  └─ 低 → 继续任务，自动忽视
  ↓
第60秒: 重新计算团队能力和下一步行动
```

---

### 突发状况2：被突然捕获/困陷

```
第一时间: 不要抵抗，收集信息
├─ 敌方是谁?
├─ 目的是什么?
├─ 有多少人?
└─ 环境是什么?

接下来: 进入谈判模式
├─ 评估敌方强硬程度
├─ 确认是杀害还是审问
├─ 设定心理防线（什么信息绝不透露）
└─ 准备说谎/启动应急计划

目标: 争取时间让外部有所行动
```

---

### 突发状况3：理性系统崩溃（发现无脸骨骼或类似事件）

```
第一步: 承认现有模型失效
├─ 停止决策（避免基于错误假设）
├─ 通知团队暂停行动
└─ 进入"观察模式"

第二步: 快速重建基础模型
├─ 收集新信息
├─ 寻找新假设
└─ 测试新假设可行性

第三步: 回到执行
├─ 基于新模型修正计划
├─ 明确承认"可能仍然错误"
└─ 保持快速调整准备
```

## 七、长期战略规划模板

### 规划维度1：3层次遗产建立

```
第1层：个人生存（即刻-3个月）
├─ 目标：活着，获得基本资源
├─ 关键指标：生存概率 >80%
└─ 成功标志：稳定获得"道"/食物/安全

第2层：团队建立（3个月-1年）
├─ 目标：建立能够与敌手抗衡的团队
├─ 关键指标：团队规模≥8人，人均能力>平均
└─ 成功标志：赢得关键游戏，获得尊重

第3层：系统理解（1年+）
├─ 目标：理解终焉之地的本质
├─ 关键指标：理论完整度、预测准确率
└─ 成功标志：主动逃脱路线清晰或论证充分
```
